# LUMINARY — Flight Engine

A browser-based 3D superhero flight game built with Three.js.

## Play

Open `index.html` directly in any modern browser — no build step needed.

## Deploy to Netlify

1. Push this folder to a GitHub repo
2. Connect repo to [netlify.com](https://netlify.com)
3. Netlify auto-detects `netlify.toml` — publish directory is `.` (root)
4. Done ✅

## Controls

| Input | Action |
|-------|--------|
| W A S D | Move |
| SPACE / SHIFT | Up / Down |
| Mouse | Look / Steer |
| Left Click | Supersonic Boost |
| C | Air Brakes |
